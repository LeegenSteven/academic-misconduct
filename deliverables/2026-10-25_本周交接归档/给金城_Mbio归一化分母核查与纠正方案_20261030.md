# Mbio 归一化分母核查与纠正训练方案（2026-10-30）

## 一、结论先行

1. **N 的定义**：归一化分母 N 为**整个梯度累积窗口内 labels != -100 的有效监督 token 总数**，不是整段序列长度。此前材料中"588"是单条序列的总长度（logits 序列维），**不是**归一化分母。
2. **原训练实现偏离目标**：原训练脚本（哈希 `1DFFDCE3CC00C6957D8EB91D8C27C844E95F2FE4C8E5E157774A617614473D22`）的 loss 为 `Σ/n_sup`（按单个 micro 有效监督 token 数做 mean），未传入 `num_items_in_batch`，与"窗口内有效监督 token 交叉熵总和 ÷ 窗口有效监督 token 总数"不等价。该偏离已被 FP32 回传中的 `reject_micro_mean` 负例对照证实（loss 差 9.4698，A/B 均拒绝）。
3. **修复后候选与原生等价**：修复候选（selected_logits + sum/num_items_in_batch）在 FP32 逻辑层 5 个正常场景全部通过（production_accum16_tail13：loss 最大差 1.19e-7，梯度/参数/delta 均为 0）。
4. **此前"58.8 倍、平均 88 倍"表述不成立**：588 是序列长度而非分母，不能据此直接调整学习率或开跑重训。
5. **建议动作**：按既定冻结方案**仅纠正训练 Mbio** 并重评新 Mbio；M0、Mscv 沿用已有结果；新旧结果分列，不覆盖历史成绩。

## 二、N 的定义与源码依据（Transformers 5.8.0）

- `trainer.py::_get_num_items_in_batch`：`num_items_in_batch = sum((batch["labels"].ne(-100)).sum() for batch in batch_samples)`——对一个梯度累积窗口内全部 micro batch 的 `labels != -100` 计数求和。
- `trainer.py::training_step`：`model_accepts_loss_kwargs=True` 且 `num_items_in_batch` 非空时，**不再除以梯度累积步数**；模型内部已按窗口有效 token 总数归一化。
- 原生路径（模型接受 `num_items_in_batch`，`fixed_cross_entropy` 内部 `sum/N`）：一个累积窗口后等效 `Σ_window_CE / N_window`，即目标口径"窗口内有效监督 token 交叉熵总和 ÷ 窗口有效监督 token 总数"。

## 三、三方对照表

| 项 | 原生 Trainer | 原训练脚本（1DFFDCE3…） | 修复后候选（9A47A2DA…/v3） |
|---|---|---|---|
| 有效监督 token 计数 | `num_items_in_batch`=窗口内 labels!=-100 求和 | 不传 `num_items_in_batch` | 传 `num_items_in_batch` |
| 实际传入的 N | 窗口有效 token 总数（production：154/126） | 无（内部 mean） | 窗口有效 token 总数 |

| 外层累积缩放 | accepts=True 不除 16 | accepts=False 除 16 | 不除 16 |
| 累积窗口等效 | Σ_all / N_window（token 加权） | (1/16)·Σ(Σ_micro/n_sup_micro)（macro 平均） | Σ_all / N_window |
| FP32 对照证据 | — | `reject_micro_mean`：loss 差 9.4698，A/B 拒 | `production_accum16_tail13`：loss ≤ 1.19e-7，梯度/参数/delta=0 |

## 四、关键数字与证据

- 诊断样本（claim_id=967）：`head_input_shape=[1,588,5120]`、`raw_logits_shape=[1,588,248320]`、`num_items_in_batch=10`、n_sup=10。588 为序列长度；10 为该样本有效监督 token 数。
- FP32 回传 production 场景（29 micro = 16 + 13）：监督 token 分母 **154 / 126**（两个梯度累积窗口），32 个可训练 LoRA 张量，Adam step 1→2，loss 最大差 1.192e-7，梯度/参数/delta 均为 0。
- `reject_micro_mean` 负例（expected_negative="micro_mean"）：loss 最大差 9.4698、梯度最大差 0.01627、参数最大差 3.55e-4、delta 最大差 2.00e-4，A/B 均拒绝——即"micro_mean"分支（原训练实现语义）与原生不等价。
- Train2141 复算：监督 token 合计 20042，平均约 9.4/样本（20042/2141=9.36）；与 production 窗口 154/126（≈16×9.6、13×9.7）量级一致。序列长度统计（min 508 / max 4924 / mean 824.39）仅反映输入序列长度，不参与归一化分母。
