# shared — 两人共用

公共层。改动会影响另一人的代码，动手前请先打招呼。

## 适合放这里

- 数据读取与字段口径（例如"什么算一次撤稿"的判定函数）
- 常量表：期刊名单、机构映射、学科分类、字段枚举
- 两边都要用的清洗/统计算法
- 绘图风格与配色（保证两张图放一起不违和）

## 不适合放这里

- 只有一边在用的实验性代码——先放自己目录，出现第二份副本时再抽过来
- 为了"以后可能用到"而提前设计的通用框架
- 重依赖或环境敏感的代码（先在自己目录跑通再说）

## 约定

- 每个模块顶部用一行注释写明用途和调用方
- 破坏性改动（改签名、改返回结构）单独一个 commit，message 以 `BREAKING:` 开头
- 本目录不放 `requirements.txt`，依赖统一由仓库根目录管理
