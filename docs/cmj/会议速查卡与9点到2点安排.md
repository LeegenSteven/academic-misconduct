# 会议速查卡

## 一句话任务

比较“引用论文怎么说”和“被引论文实际提供了什么证据”，输出准确、不准确、无实质关联三类语义风险。

## 必须记住的8个数字

| 数字 | 含义 |
|---:|---|
| 100 | 核心被引论文数 |
| 3,063 | 正式引用实例数 |
| 1,863 | 原始细粒度标注中的ACCURATE |
| 1,200 / 39.18% | 原始标注中的全部问题引用，包含82条INDIRECT |
| 1,945 / 901 / 217 | 建模三分类：准确/不准确/无关 |
| 0.53 | 引用句查询时证据检索Recall@20 |
| 0.59 / 0.52 | 最佳MultiVerS的Micro-F1/Macro-F1 |
| 0.75 | 使用人工引用上下文和人工证据时的Macro-F1 |

## 方法链条

`引用句 -> BM25召回60句 -> MonoT5重排序 -> Top-20 -> MultiVerS -> 三分类概率`

## 你的三个判断

1. 先复现官方baseline，不急着换大模型。
2. 优先改证据检索，因为分类器看不到正确证据时无法正确判断。
3. 治理场景应保留INDIRECT等细粒度信息，不宜只保留三分类。
