## 4. 3条差异的正式结论

对比结果：

```text
外层上下文识别文件：2143 + 317 + 606 = 3066
正式人工标注和claims：2141 + 316 + 606 = 3063
差异：训练集2条，验证集1条，测试集0条
```

已确认事项：

1. 这3条并非三条完全相同的重复行。
2. 2024年3月发布的外层 `train/dev/test.jsonl` 与2025年2月更新的 `annotations.zip` 和 `claims-*.jsonl` 不是同一次导出的同一数据版本。
3. 两类文件不共享可直接对齐的样本ID；公开仓库未提供版本映射表、生成脚本或过滤日志。

当前可复述的结论：后期正式标注和MultiVerS数据相对早期上下文识别文件发生过清洗、过滤或重整，但公开资料不足以证明具体是哪3条以及具体过滤规则。该差异应记录为“版本不一致待追踪”，不能直接称为数据错误。

## 5. 后续实验的版本口径

1. **最终三分类与证据检索实验**：以 `annotations.zip`、`claims-train/dev/test.jsonl` 和 `corpus.jsonl` 的3,063条正式数据为准。
2. **引用上下文识别子任务**：只能使用外层3,066行文件，并在报告中明确它与最终三分类数据不是完全一一对应的同一版本。
3. **统一端到端实验**：在获得作者映射表前，不将3,066行的上下文模型输出直接称为对3,063条最终claim的严格端到端结果。
4. 每次实验结果须记录本清单中的SHA256、划分、随机种子、命令、模型版本和生成日期。
