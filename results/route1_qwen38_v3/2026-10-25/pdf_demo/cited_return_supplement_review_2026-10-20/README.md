## 复算方法与边界

保留收到脚本的原始字节，没有改写后冒充原脚本。原文件在模块加载时就会创建作者电脑上的固定输出目录，主程序路径也指向作者电脑。本地复算只加载已检查的导入、检索常量及原检索函数，注入本机的同版 `pdf_text/`，没有执行其主程序或顶部目录创建语句。

输入仍是冻结的 20 条 `cited_retrieval_requests.jsonl`，原 PDF 和缓存块的哈希已核对。本次 Python 为 3.12.14、NumPy 为 2.3.5；师兄报告原环境是 Python 3.9。本次核实的是同版检索函数对当前冻结输入的结果复现，不宣称恢复了师兄的原运行进程、环境或旧终端日志。

本次新产生的 `cpu_replay.log` 是李云侧的本地 CPU 复算日志，不能称作陈明进原运行日志。精确复算时间与原执行日期分开保存。

实际参考文献过滤实现是正则与首词启发式，没有页位判断；函数注释里提到的“后半部分”不是已实现的条件。本次按实际代码复现，没有把注释当成额外规则，也不因此宣称参考文献已被完全排除。
