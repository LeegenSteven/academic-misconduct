## 执行边界

本目录是 v3 输入准备草稿，`formal_v3_input_release=false`。新提示词只要求分类标签；候选不足时可返回 `failure_status=insufficient_evidence`，该状态不是第四类标签。后续 v3 入口需要正确处理范围暂停和失败状态，不能把草稿直接交给旧 v2 评测脚本并声称正式验收通过。

独立解释模块尚未运行。后续还需范围确认、统一入口的实际分类与独立解释、模型及 adapter 身份核验、真实响应与日志回收、双方人工语义核对及裁决。分类正确性、解释语义、定位有效性和工程闭环分别统计。当前工程闭环尚未验收；正式定位率、解释通过率和分类准确率均未知。达到定位下限需在固定 20 点中至少 16 点被人工确认有效，不能用技术回放代替。

本轮不修改已冻结的 v2 数据、6 个 Test 单元或其指标；不重新训练，不声称是全新盲标批次。原始回传和历史检查记录均保留。本地文件尚未提交或上传 GitHub。
