# 25条候选双人独立语义标注准备包

本包准备了25个固定引用标记、原始施引段落、被引全文阅读页和未经修改的PMC XML。没有填写任何人的判断，不代表25条均已合格或完成标注。此前R2EXP-PMC-01、02、09、16、17继续挂起，不在本包。

打开《开始查看.html》逐条查看；两位标注者各自领取独立空表及相同的cards、fulltext、raw_xml文件夹。李云表与陈明进表的输入完全一致；不要把已填写的一方表格发给另一方。空表中的annotator_id等由实际标注者填写。

每条候选按XML原始顺序固定首次定位到的目标引用标记，不按结构密度、模型判断或预计标签选引用点。完整段落只是语境，不把其中所有主张自动归给当前被引文。请先确认黄色引用标记所覆盖的施引分句，将该分句原样填入cited_clause_text；scope_status填明确或待确认。若无法明确归属，留空label并说明疑点，不强行判断。两人若填写的分句范围不同，应保留各自原值，先核对范围再决定能否比较标签；不能直接算作同一范围的一致或分歧。

label只用ACCURATE、NOT_ACCURATE、IRRELEVANT。ACCURATE需要被引原文对该引用范围有支持；NOT_ACCURATE需要说明原文与施引主张的具体矛盾、夸大或关键条件改变；IRRELEVANT需要核实被引内容与对应引用主张无关。只因证据不足、检索不到相同词句或全文无法可靠核实，不直接判为IRRELEVANT或NOT_ACCURATE。

evidence_status填可定位、待定位、源文缺失或待核；无法可靠判断时label留空，reason保留原因。定位写PMCID、body/p段落序号及段落id（如有），并填写原始证据文本；这些是XML定位，不是PDF页码。图表、公式和补充材料可能无法在纯段落阅读页完整呈现，需回到原始全文核实，不能以本页没有图像作为无证据的依据。

请填写annotator_id、scope_status、cited_clause_text、label、evidence_status、evidence_locator、evidence_text、reason、review_status、completed_at，并保留所有输入列不变。review_status可填完成、待确认、待补证；只有实际完成的记录才填完成。不要在此阶段共同填写最终裁决。

本包刻意不提供网络密度、截断标记、排名、对方判断或模型结果。结构数据由成员3另行保留；两人独立结果回收后再核对引用范围、证据和分歧，最后形成语义记录与结构字段的关联。当前未计算一致率，也没有正式完成标签或裁决。

源码许可文字保留于各阅读页及原始XML；本包只作为研究复核材料，不推定所有文章具有相同的后续使用许可。文件SHA-256见package_manifest.json。
