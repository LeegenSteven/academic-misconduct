# results — 产出

图表、表格等分析产出。

## 组织

按主题分子目录，避免两人的文件互相覆盖：

```
results/
├── trend/            # 撤稿趋势
├── network/          # 合作关系网络
└── case-study/       # 案例
```

## 什么该提交

| 类型 | 提交 | 说明 |
|------|------|------|
| 论文用的最终图（PDF/SVG） | ✅ | 要能对上具体版本 |
| 最终表格（CSV） | ✅ | 论文数字的来源 |
| 中间过程图（PNG） | ❌ | 重跑就有，会撑大仓库 |
| 含真实人名的明细表 | ❌ | 见 `data/README.md` 的伦理说明 |

## 命名

```
results/<主题>/fig1-<内容>.<格式>
results/<主题>/table2-<内容>.csv
```

编号跟着论文里的图表编号走，这样改稿时"图 3 换一下配色"能直接定位到文件。
